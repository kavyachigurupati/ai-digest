# AI News Digest — Setup & Run Instructions

## Project Structure

```
digest/
├── scraper.py          # Fetches RSS feeds → saves raw_articles.json
├── analyzer.py         # Reads raw_articles.json → calls Claude → saves digest.json
├── app.py              # Flask server → reads digest.json → shows latest 5
├── sources.json        # RSS feed config (edit to add/remove sources)
├── raw_articles.json   # Auto-generated by scraper.py (intermediate file)
├── digest.json         # Auto-generated, append-only article history
└── .env                # Your API keys (create this manually)
```

---

## Step 1 — Prerequisites

Make sure you have these installed:

- Python 3.9+
- Poetry (`pip install poetry`)

---

## Step 2 — Install Missing Packages

Your `pyproject.toml` is missing two packages needed for scraping.
Run this inside your project directory:

```bash
poetry add feedparser beautifulsoup4
```

Your existing packages (anthropic, flask, requests, python-dotenv) are already there.

---

## Step 3 — Create Your .env File

Create a `.env` file in the same directory as the Python files:

```
ANTHROPIC_API_KEY=your_actual_key_here
GOOGLE_API_KEY=your_google_key_here   # optional, only needed as fallback
```

---

## Step 4 — Copy the Files

Make sure all these files are in the same directory:
- `scraper.py`
- `analyzer.py`
- `app.py`
- `sources.json`
- `.env`

---

## Step 5 — Run the Pipeline

Always run in this order:

### 1. Fetch articles (scraper)
```bash
poetry run python scraper.py
```
This fetches RSS feeds and Hacker News, saves results to `raw_articles.json`.
Expected output:
```
Fetching RSS: Netflix Tech Blog ...
  Found 4 new articles
Fetching RSS: Cloudflare Blog ...
  Found 5 new articles
...
Scraper done. 32 raw articles saved to raw_articles.json
```

### 2. Summarize with Claude (analyzer)
```bash
poetry run python analyzer.py
```
This reads `raw_articles.json`, calls Claude API, appends 5 summaries to `digest.json`.
Expected output:
```
Loaded 32 raw articles from raw_articles.json
Calling Claude API ...
  Claude responded.
  Parsed 5 summarized articles from Claude
  Appended 5 articles to digest.json
  Total articles in digest: 5
```

### 3. Start Flask server
```bash
poetry run python app.py
```
Then open your browser at: `http://localhost:5000`

---

## Step 6 — Expose via Cloudflare Tunnel

With Flask running, in a separate terminal:

```bash
cloudflared tunnel --url http://localhost:5000
```

Cloudflare will give you a public URL like `https://xyz.trycloudflare.com`.
Share that with your testers — no installation needed on their end.

---

## Running Again (Next Day)

Just repeat Steps 5.1 and 5.2. New articles will be appended to digest.json.
The Flask server always shows the latest 5 — keep it running or restart it.

```bash
poetry run python scraper.py
poetry run python analyzer.py
```

Flask server does NOT need to be restarted — it reads the file fresh on each page load.

---

## Optional — Auto-run Every 24 Hours (Mac/Linux)

Add a cron job to run the pipeline automatically:

```bash
crontab -e
```

Add this line (runs at 8am daily):
```
0 8 * * * cd /path/to/your/digest && poetry run python scraper.py && poetry run python analyzer.py
```

## Troubleshooting

| Problem | Fix |
|---|---|
| `ModuleNotFoundError: feedparser` | Run `poetry add feedparser beautifulsoup4` |
| `No articles yet` shown in browser | Run scraper.py then analyzer.py first |
| Claude returns invalid JSON | Check your ANTHROPIC_API_KEY in .env |
| Cloudflare URL not working | Make sure Flask is running first (`app.py`) |
| Same articles showing after re-run | Working as intended — deduplication skips seen URLs |

## What Changed vs aidigest.py

| | aidigest.py (old) | New pipeline |
|---|---|---|
| Who finds articles | Claude searches the web | scraper.py fetches RSS |
| Claude's job | Search + summarize | Summarize only |
| Cost per run | Higher (web search calls) | Lower (no search tool) |
| Web search tool | Yes | No (removed intentionally) |
| Output | Printed to terminal | Saved to digest.json |
| Viewing | Terminal only | Browser via Flask |
