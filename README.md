# AI Digest

A daily AI/Tech news digest tool that fetches and summarizes the latest AI news. It supports both Anthropic's Claude and Google's Gemini as fallback.

## Setup

### 1. Install Dependencies

This project uses [Poetry](https://python-poetry.org/) for dependency management.

```bash
poetry install
```

### 2. Install Additional Scraping Packages

Two packages are required for the RSS scraper that are not in pyproject.toml yet:

```bash
poetry add feedparser beautifulsoup4
```

### 3. Configure API Keys

Create a `.env` file in the project root:

```env
ANTHROPIC_API_KEY=your_anthropic_key_here
GOOGLE_API_KEY=your_google_key_here
```
*(If the Anthropic key is missing or set to `your_api_key_here`, the app will automatically fall back to Google Gemini).*

## Usage

### Option 1: Run via Terminal (Original)

To generate the digest directly in your terminal using Claude's web search:

```bash
poetry run python ai-digest.py
```

### Option 2: Run the New Pipeline (Recommended — Cheaper)

The new pipeline separates scraping from summarization.
Claude no longer searches the web — it only summarizes pre-fetched articles.
This significantly reduces API cost per run.

**Step 1 — Fetch articles from RSS feeds:**
```bash
poetry run python scraper.py
```
Fetches from all sources in `sources.json`, saves to `raw_articles.json`.

**Step 2 — Summarize with Claude:**
```bash
poetry run python analyzer.py
```
Reads `raw_articles.json`, Claude picks best 5 and summarizes, appends to `digest.json`.
Prints token usage and cost in USD after each run.

**Step 3 — View in browser:**
```bash
poetry run python app.py
```
Open [http://localhost:5000](http://localhost:5000) to see the latest 5 articles.

Always run in this order: `scraper.py` → `analyzer.py` → `app.py`

### Option 3: Run via Web Server (Original Streaming UI)

We have a Flask server that provides a terminal-like streaming UI in the browser.

1. **Start the server:**
   ```bash
   poetry run python server.py
   ```
2. **Open in browser:**
   Go to [http://localhost:3000](http://localhost:3000). The digest will automatically run and stream output to the page on visit.

### Option 4: Publicly Share (Cloudflare Tunnel)

To share the running server with others over the public internet, you can use a free Cloudflare Tunnel.

1. Install Cloudflared (Mac via Homebrew):
   ```bash
   brew install cloudflare/cloudflare/cloudflared
   ```
2. While `app.py` or `server.py` is running, open a **new terminal tab** and run:
   ```bash
   # For new pipeline (port 5000)
   cloudflared tunnel --url http://localhost:5000

   # For original streaming server (port 3000)
   cloudflared tunnel --url http://localhost:3000
   ```
3. Look for the output line containing `trycloudflare.com`. Share that URL with testers — no installation needed on their end.

## Mac SSL Fix

If you see `SSL: CERTIFICATE_VERIFY_FAILED` errors when running `scraper.py`, this is a known Python 3.9 Mac issue. It is already handled in `scraper.py` automatically with:

```python
ssl._create_default_https_context = ssl._create_unverified_context
```

No action needed — this only affects reading public RSS feeds.

## Troubleshooting

| Problem | Fix |
|---|---|
| `ModuleNotFoundError: feedparser` | Run `poetry add feedparser beautifulsoup4` |
| `No articles yet` in browser | Run `scraper.py` then `analyzer.py` first |
| SSL certificate errors | Already handled in scraper.py automatically |
| Claude returns invalid JSON | Check `ANTHROPIC_API_KEY` in `.env` |
| `No new articles` after re-run | Working as intended — deduplication skips seen URLs |
| Cloudflare URL not working | Make sure Flask (`app.py`) is running first |

## Evaluation Framework

The pipeline includes a structured eval system to measure summarization quality and relevance filtering accuracy. See [EVALS.md](./EVALS.md) for the full design.

**What is being evaluated:**

| Component | Measures | Target |
|---|---|---|
| LLM-as-Judge | Hallucination, faithfulness to source | > 4.0 / 5.0 |
| BERTScore | Semantic similarity to reference summaries | F1 > 0.85 |
| Relevance Precision & Recall | Are the right articles being selected? | Precision > 80%, Recall > 75% |
| Consistency Testing | Stability of output across multiple runs | F1 > 0.90 |
| Human Feedback UI | Real user satisfaction with articles and summaries | Thumbs-up > 70% |

**Status:** Planning — implementation in progress. Results will be added to [EVALS.md](./EVALS.md) as each component is built.
